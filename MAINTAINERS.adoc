== How to Reach a Maintainer

[cols="1,2",options="header"]
|===
| Topic
| Route

| Specification question
| GitHub issue.

| Proposed change
| GitHub issue first, then a pull request.

| Architectural proposal
| GitHub issue with the problem statement, then an ADR.

| Security issue
| Private vulnerability reporting. Never a public issue. See `SECURITY.adoc`.

| Automation appears stuck
| Check the open `automation-health` issue, then run the *Manual recovery*
  workflow.
|===

== Escalation

. Failing gate on `main`: open an issue, do not disable the gate.
. Automation silence: see `SUCCESSION.adoc`, section on disabled automation.
. No maintainer reachable: see `SUCCESSION.adoc`, section on an abandoned
  account.
