A repository with one maintainer and one personal access token has no
succession path. ADR-0005 requires that automation keep working without the
continuous presence of any one person.

== Escalation

. Automation failure: check `automation/health.json` and the open
  `automation-health` issue.
. Content dispute: open an issue, do not edit records silently.
. Security concern: contact the security contact privately, see
  `SECURITY.adoc`.
. No maintainer reachable: see `RECOVERY.adoc` and the succession
  documentation in the specification repository.
